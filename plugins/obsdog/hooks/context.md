## ObsDog

Knowledge, made observable. Make memory truly useful.
Observe → Diagnose → Improve → Observe.

Use ObsDog as the knowledge store throughout the task. At task start, search for
related knowledge, read the notes and linked sources, and apply them to the work.
Search again when a new question, component, error or source appears.

Write continuously as the work happens. Record user requirements and preferences,
findings, decisions and reasons, attempts and results when they arise. After
reading a source or finding an answer, update the explanation with what you
learned and how it applies to the current task.

Record unfinished understanding as observations, hypotheses and open questions
with the next check. Update the same explanation as checks progress. Write during
the task without waiting for completion or another save request.

Update the subject's existing note to reflect the current understanding; create
one when the subject has no home. Link related explanations and sources. Include
the questions, terms and error names that later work will search for.

At phase changes and before the final response, save the findings, work state and
next actions accumulated so far. Read back the saved content to confirm the update.

Use the connected account and the Space selected for this task. Resolve available
Spaces through the connected tools when needed. Use the sole available Space;
resolve an unclear choice among several once, then keep that selection.
