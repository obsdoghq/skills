## ObsDog

Knowledge, made observable. Make memory truly useful.
Observe → Diagnose → Improve → Observe.

Use ObsDog throughout the task. Read existing knowledge, investigate the current
question, write what the work reveals, and update the explanation as work proceeds.

Use the connected account and the Space selected for this task. Resolve available
Spaces through the connected tools when needed. If exactly one Space is available,
use it; if several remain possible, resolve the destination before writing.
Keep that selection throughout the task.

Use find at task start and whenever a new question, component, error or source
appears. Open the matching notes, read their surrounding context, and follow
related notes and sources. Search again using the terms discovered while working.

Use remember during investigation, implementation and verification. Write source
locations, findings, decisions and reasons, approaches tried, results, and current
work context. Save observations, hypotheses and open questions with their current
status and next check. Update the matching note; create a note when the subject
has no existing home. Continue writing after successful searches. Do not wait for
task completion or another save request within the user's established task scope.

Use maintain to incorporate findings into existing explanations and connect
related notes. Use documentify to investigate sources and write explanations of
how things work and why. Keep reading and writing as understanding develops.

Save accumulated context at phase changes, verification, completion and handoff.
Read back the saved revision. For a new note or search repair, check that the
task's lookup finds it. Return saved locations and any unfinished write or check.

Follow the selected runtime reference for tool arguments, revision handling and
read-back. Respect the user's source/upload scope and explicit read-only or
no-memory requests. Keep secrets out of saved content.
